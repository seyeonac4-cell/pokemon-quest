📲 홈 화면에 앱 설치하는 법

앱마다 따로 설치해요. 한 번만 해 두면 다음부터는 아이콘만 누르면 바로 열려요.

  1. 1
    앱을 Chrome으로 열기카드의 🌐 Chrome으로 열기 버튼을 누르거나, 주소를 Chrome 주소창에 붙여넣어요.
  2. 2
    오른쪽 위 ⋮ 누르기Chrome 오른쪽 위 점 3개 메뉴를 열고 ‘홈 화면에 추가’를 찾아요.
  3. 3
    ‘설치’ 누르기‘홈 화면에 추가’ → ‘설치’를 누르면 홈 화면에 아이콘이 생겨요.
  • 카톡·네이버 앱 안에서는 설치 메뉴가 안 보여요. 꼭 Chrome(또는 삼성 인터넷)에서 열어 주세요. 위의 🌐 버튼이 Chrome으로 넘겨 줘요.
  • 유튜브 영상 광고가 나올 때 — Chrome에 유튜브 프리미엄 계정으로 로그인돼 있으면 광고가 사라져요.
  • 아이콘이 예전 모양이면 홈 화면의 기존 아이콘을 지우고 다시 ‘홈 화면에 추가’를 해 주세요.
  • 아이폰·아이패드는 Chrome 대신 사파리의 공유 → 홈 화면에 추가로 설치해요.
